#  FootballVerse

A responsive football website that displays live, upcoming, and finished football matches using the ESPN API.

##  Live Demo

** [View FootballVerse](https://venuvarshith12-bit.github.io/Footballverse/)**

##  Features

*  Live football match updates
*  Upcoming matches
*  Finished matches
*  Home and away team information
*  Team logos
*  Match date and time
*  Match filtering
*  Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* ESPN API
* GitHub Pages

##  API

Match data is fetched from the ESPN Soccer API.
